# cmk Integration for CLion

This plugin lets `cmk` own CMake configuration for `cmk-*` profiles generated in `CMakeUserPresets.json`, while CLion retains its native CMake project model, incremental builds, test runners, run configurations, and debugger integration.

## How it works

1. Running `cmk config` (or opening a configured `cmk` project) writes `CMakeUserPresets.json` with `cmk-<preset>` configure presets—including compiler paths, C++ module scanner/stdlib definitions, dependency prefixes, `ccache` settings, and `LLVM_SYMBOLIZER_PATH`.
2. Whenever CLion reloads a `cmk-*` configure preset in a project with `cmk.yaml`, the plugin intercepts the configure step and runs:
   ```sh
   cmk config --if-stale --build <profile-build-directory>
   ```
   Live output streams directly to CLion's CMake console, and non-zero exit codes surface full `stdout`/`stderr` diagnostics.
3. The plugin then replaces CLion's own `cmake` configure invocation with a fast no-op (`cmake -E true`), allowing CLion to load the CMake File API replies generated by `cmk` without overwriting `cmk`'s injection stamp or causing file-watcher reload loops.
4. Non-`cmk` presets and CMake projects without `cmk.yaml` keep CLion's default behavior.

> **Tip:** CLion also natively recognizes the `# yaml-language-server: $schema=...` header emitted by `cmk init` / `cmk new`, providing inline autocompletion and validation when editing `cmk.yaml`.

## Configuration

Under **Settings | Build, Execution, Deployment | cmk**, you can:
- Enable or disable the integration per project.
- Point CLion at a custom `cmk` binary path when `~/.local/bin` is not in the desktop session's `PATH`, and verify it with the **Test** button.

## Building from source

The adapter targets **CLion 2026.2 and 2026.3** (it hooks the internal `CMakeRunnerStep` extension point). Build it with JDK 25:

```sh
cd integrations/clion-cmk
./gradlew buildPlugin -PclionPath=/path/to/clion
```

When `-PclionPath` is omitted, Gradle downloads CLion 2026.3 as the build SDK. The installable plugin archive is written to `build/distributions/`.
